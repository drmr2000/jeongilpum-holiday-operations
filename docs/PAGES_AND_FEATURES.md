# 페이지와 기능

## 공통 navigation과 branding

- `AppNav`는 키오스크, 판매장, 작업장, 설정으로 이동합니다.
- 데스크톱에서는 우측 세로 배너, 좁은 화면에서는 우측 하단 가로 배너를 사용합니다.
- 정일품 로고와 `정일품 정육식당` 표기를 유지합니다.
- 고정 계절 문구와 판매기간 안내를 사용하지 않습니다.

## `/kiosk`, `/kiosk/custom`

고객 키오스크는 고정된 흐름입니다. 기능 개선, 디자인 변경, 데이터 모델 교체를 이유로도 이 두 화면을 수정하지 않습니다.

- 활성 상품과 날짜별 `daily_limit` 잔여수량을 조회합니다.
- 주문 초안은 제출 전 브라우저 `sessionStorage`에만 저장합니다.
- 방문예약, 택배예약, 현장판매 주문을 접수합니다.
- 맞춤주문은 `/kiosk/custom`에서 작성한 뒤 키오스크 주문 초안으로 돌아옵니다.
- `POST /api/orders` 성공 후에만 주문 완료를 표시합니다.
- 달력은 서울 기준 오늘부터 365일까지 표시합니다. 판매기간 설정은 없습니다.

## `/sales`

판매장 화면은 `work_items` 중심의 작업 테이블입니다. 행 하나는 상품과 수령일시가 정해진 고객 작업입니다.

### 상단 현황

- `received`, `confirmed`, `in_progress`, `ready`, `completed` 상태별 통계 타일을 표시합니다.
- 각 타일은 현장판매, 현장예약, 택배예약 소계를 함께 표시합니다.

### 작업 탭

- 기본 조회 범위는 당일 수령·발송 작업입니다.
- 고객 도착 또는 수령시각이 임박한 작업을 강조하고 앞쪽에 정렬합니다.
- 상태, 수령방법, 기간, 검색어로 필터링합니다.
- 행 단위의 `고객 도착`과 `주문 확인` 전환은 모두 되돌릴 수 있습니다.
- 행을 선택하면 모든 작업 필드를 편집하는 팝업을 엽니다.
- 새 작업 행 생성, 행 복제, 다중 선택을 지원합니다.
- 다중 선택 작업에는 상태, 수령일시, 결제 상태·금액, 복제, 삭제가 포함됩니다.

### 미수·고객 탭

- 구매자 이름과 전화번호를 기준으로 주문을 그룹화합니다.
- 별도 고객 장부 테이블을 사용하지 않습니다.
- 잔액은 각 `orders` 행의 `total_amount - paid_amount` 합계로 계산합니다.
- 주문 단위로 `unpaid`, `partial`, `paid`와 입금액을 직접 수정합니다.

## `/workshop`

작업장 화면은 결제 금액을 중심으로 구성하지 않으며, 작업 준비와 생산 흐름을 우선합니다.

- `오늘 현장`: 당일 현장예약 작업을 표시합니다.
- `택배`: 당일 택배예약 작업을 현장 작업과 분리하여 표시합니다.
- `상품별`: 상품별 필요수량, 준비수량, 남은수량을 집계합니다.
- 부가 기능: 생산 관리와 패키지 화면으로 이동합니다.
- 작업 상태 변경은 운영 세션과 작업 항목 버전을 확인한 뒤 기록합니다.

## `/workshop/production`

- 날짜별 작업 수요와 가용 Skin Pack을 조회합니다.
- production batch 생성, 생산 목표 변경, 추적성 번호 구간 변경, Skin Pack 생성, batch 완료를 처리합니다.
- batch별 Skin Pack 라벨 CSV를 다운로드합니다.

## `/workshop/packages`

- 최근 package 목록과 연결된 작업의 수령 정보를 조회합니다.
- package 상세에서 연결 Skin Pack과 라벨 미리보기를 조회합니다.
- 작업 항목 단위 package 생성과 package 재배정을 지원합니다.
- package별 Skin Pack 라벨 CSV를 다운로드합니다.

## `/settings`

설정은 상품 편집 전용 화면입니다.

- 상품 행을 선택하면 편집 팝업을 엽니다.
- category, 이름, 부제, 설명, 가격, 표시중량, 이미지 URL, badge, 정렬순서, 활성 상태를 수정합니다.
- `daily_limit`은 이 화면에서만 수정합니다.
- 판매기간, 방문·택배 가능기간, 운영 암호 변경, 키오스크 문구 설정 UI는 제공하지 않습니다.
